# HouseHunt User Flow

## Overview
HouseHunt is a MERN stack based web application that allows users to search rental properties, list houses for rent, and manage bookings.

## User Flow

1. User visits the HouseHunt website homepage.
2. User registers a new account or logs in.
3. After login, user can browse available rental properties.
4. User can filter properties by location, price, and type.
5. User clicks a property to view details.
6. User sends a booking request to the owner.
7. Owner can manage property listings.
8. Admin reviews and approves property listings.
9. User can track booking status from the dashboard.
