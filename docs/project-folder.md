# Project Folder Structure

## Overview
The HouseHunt project follows the MERN stack architecture. The application is divided into two main parts: the frontend (client) and backend (server).

## Main Project Structure

```
HouseHunt
│
├── client
│   ├── public
│   └── src
│       ├── components
│       ├── pages
│       ├── services
│       └── App.js
│
├── server
│   ├── config
│   ├── controllers
│   ├── models
│   ├── routes
│   ├── middleware
│   └── server.js
│
└── docs
```

## Explanation

**client**  
Contains the React frontend application responsible for the user interface.

**server**  
Contains the Node.js and Express backend responsible for APIs, authentication, and database interaction.

**docs**  
Contains documentation files describing the architecture and setup of the project.
