# Client Setup (React Application)

## Overview

The frontend of the RentEase application is built using React.js.

## Installing React Application

To create the React project, run the following command:

```
npx create-react-app client
```

This command creates a React project inside the client folder.

## Install Required Packages

After creating the React application, install additional dependencies:

```
npm install axios react-router-dom bootstrap
```

## Running the React Application

Navigate to the client folder and run:

```
npm start
```

The application will start on:

```
http://localhost:3000
```

## Purpose

The React client handles:
- UI rendering
- User interactions
- API communication with backend
