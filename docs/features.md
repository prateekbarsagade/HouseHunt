# Application Features

## Overview

RentEase is a MERN stack based house rental platform that allows users to browse rental properties, list their own properties, and manage bookings through a simple web interface.

## Core Features

### User Authentication
Users can register and login securely using authentication mechanisms.

### Property Listing
Property owners can add, update, and delete property listings.

### Property Search
Users can search properties using filters such as:
- Location
- Price
- Property type

### Property Details
Users can view detailed information about a property including:
- Images
- Price
- Description
- Location

### Booking System
Users can send booking requests for properties.

### Admin Panel
Admins can:
- Approve property listings
- Manage users
- Remove inappropriate listings

### Dashboard
Users can view their activities such as:
- Properties listed
- Booking requests
