# Roles and Responsibilities

## Overview

The RentEase project is developed collaboratively where each team member contributes to specific parts of the application.

## Roles

### Frontend Developer
Responsible for building the user interface using React.js.

Responsibilities:
- Designing UI components
- Implementing navigation using React Router
- Connecting frontend with backend APIs

### Backend Developer
Responsible for server-side development using Node.js and Express.

Responsibilities:
- Creating REST APIs
- Implementing authentication
- Handling database operations

### Database Developer
Responsible for designing and managing the MongoDB database.

Responsibilities:
- Creating schemas
- Managing collections
- Optimizing queries

### Project Architect
Responsible for designing the overall structure of the application.

Responsibilities:
- Defining project architecture
- Designing folder structure
- Documenting system flow
